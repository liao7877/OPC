# 受控词表（glossary）

> **作用**：`tags` 归一，防同义分裂导致检索漏——「工单 / 任务 / ticket」三个词写三条，检索必漏。
> **维护**：本级管理员（公司级 = 总管）；新增术语先查本表，已有则复用，不造同义词。
> **消费**：`opc_model --sync-index` 生成 INDEX.md 时读本表做 tag 归一；未登记的词照原样收录并在索引里标 `未归一`。
> **边界**：本表是**工具**不是知识条目；术语的释义本身要入库时，另建 `type: glossary` 条目。

## 格式

```
| 标准词 | 同义（一律改写为标准词） | 禁用（理由） |
```

## 术语表

| 标准词 | 同义（改写为标准词） | 禁用 |
|---|---|---|
| 工单 | 任务、ticket、TSK | 待办（太泛） |
| 技能 | skill、能力 | 工具（歧义） |
| 巡检 | patrol、巡查 | 检查（歧义） |
| 看板 | dashboard、驾驶舱 | 面板 |
| 知识库 | KB、knowledge | 资料库 |
| 上浮 | promotion | 晋级（那是硬度轴，见下） |
| 晋级 | 固化、solidify | 上浮（那是归属轴） |
| 总管 | E0000、调度 | 老板 |
| 工位卡 | session 卡 | 会话（歧义） |

> **上浮 vs 晋级**（两轴正交，勿混用）：**上浮** = 归属轴（员工→团队→公司，物理搬家）；**晋级** = 硬度轴（条目→方法卡→技能→机制，改写形态）。详见 MECHANISM_PLAN §十七 开头。
