# 公司规章制度目录

> **本目录是公司规章制度的唯一落点**（文件系统即真相）。规章制度以**原始文件格式**存放（word / excel / pdf / md 等，不做预处理）。
> **公司级 / 团队级 / 个体级规章原文件统一放这里**——不按层级分目录、不复制到团队/员工目录（原文件可能混合多层内容，分不清就不拆，靠落实时判定）。

## 使用方式（给总管 E0000）
- 用户说"把 XX 规章制度落实一下" → 按 `dispatch-sop` 的「规章制度落实 SOP」执行：
  1. 到本目录定位规章文件（格式多样，自行解析）
  2. **按条款判定范围**（公司 / 团队 / 个体，一份混合规章可逐条拆分分别落实）
  3. 出改动清单 → 用户确认 → 备份 `.bak` → 执行改动（AGENTS.md / team.md / skills / INDEX.md）
  4. 落实后在被改的 team.md / 员工 AGENTS.md 留「适用规章」引用行（只引用不复制）：`适用规章：../../companies/<本司ID>/公司规章制度/XX.md`
  5. 汇报改动与回滚方式

## 组织建议
- 一个规章一个文件，命名清晰：如 `考勤管理制度.md`、`代码规范.md`
- 可建子目录分主题（如 `人事/` `技术/` `流程/`），按需扩展
- 新规章直接放入即生效（无需登记，总管按文件名/主题定位）
- **不按层级拆分**：团队规章/个体规章的原文件也放这里（内容混合时由落实阶段按条款处理）
