# 资料归档规范（material-archive）

> 用途：确保用户投喂的项目资料不丢、不混、可追溯。
> 级别：E0002 私有技能（初版）。

## 目录约定（workspace/）
- `inbox/`        刚接收、待整理的原始资料
- `projects/`     按项目归档，如 projects/XX项目/
- `drafts/`       草稿与中间产物

## 接收流程
1. 收到资料（对话投喂或文件）→ 先落 `inbox/`，命名 `YYYYMMDD-来源-主题.扩展名`
2. 快速判断归属项目 → 移入 `projects/对应项目/`（无对应项目则建）
3. 提取关键信息（目标/干系人/deadline/风险）→ 记一笔到该项目的 `README.md` 或 memory
4. 向用户回执：已收到 X 份、归到哪、是否缺关键信息

## 检查清单
- [ ] 原文件已存 inbox 或 projects
- [ ] 命名规范团队一致
- [ ] 关键信息已提取
- [ ] 已向用户回执

## 注意事项
- 绝不删除用户原始资料
- 资料缺失关键信息 → 标注并提醒用户，不替用户补全
