# 周报与状态报告生成器（status-report）

> 用途：把项目当前状态整理成结构化汇报。
> 级别：E0002 私有技能（初版）。

## 报告结构
1. **整体结论**（一句话：正常 / 有风险 / 受阻）
2. **本周/本阶段进展**（已完成项 + 完成度%）
3. **风险与阻塞**（列表，带影响与建议）
4. **待决策项**（需要总管/用户拍板的事）
5. **下一步计划**（下周/下阶段）

## 执行步骤
1. 汇总 workspace/projects/ 与各任务状态
2. 按上面 5 段组织内容，结论先行
3. 表格呈现进展与风险
4. 输出到 deliverables/ 或回对话；重要变更同步总管（E0000）

## 注意事项
- 不粉饰风险，受阻就明说
- 待决策项要给出建议选项，别只抛问题
