# 常设事务区（affairs/）

> 无终点、持续养护资产的工作落位于此（长期内容运营、文件/目录维护、渠道经营……）。
> 一个事务 = 一个目录 AFFxxxx-标题/：affair.md（契约：owner/cadence/status + 例行说明正文）+ assets/（被维护的资产）+ logs/（过程留痕）。
> 与项目的分界：**项目有终点，事务没终点**。每次干活在员工 worklog 记 type=事务 + aff=AFFxxxx；大活照常开工单（条目同时带 aff）。
> 节奏保障：cadence 声明 + 生成器按 worklog 推导"距上次推进"，超期看板黄条。
