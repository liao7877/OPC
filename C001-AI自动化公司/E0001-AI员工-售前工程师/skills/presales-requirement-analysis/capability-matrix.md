# presales 能力矩阵与知识储备（capability-matrix）

> SKILL.md 的 Level 3 附属：自查能力短板、规划补课方向时读。能力要求 = 表格左列，输出物 = 检验标准。

## 需求分析师能力栈

| 能力维度 | 具体要求 | 输出物 |
|---------|---------|--------|
| **需求获取** | 熟练运用访谈、问卷、焦点小组、现场观察、竞品分析、用户日志分析等方法 | 需求调研报告、用户画像 |
| **需求分析** | 掌握KANO模型、MoSCoW法则、用户故事映射、UML建模、用例分析、业务流程梳理 | 需求优先级清单、业务流程图、用例图 |
| **需求建模** | 能绘制业务流程图、系统流程图、时序图、状态图、ER图、原型图 | 各类模型图、Axure/墨刀原型 |
| **文档撰写** | 能独立输出BRD、MRD、PRD、SRS等标准化需求文档 | BRD/MRD/PRD/SRS文档 |
| **需求管理** | 掌握需求变更控制、需求跟踪矩阵（RTM）、需求评审与确认流程 | 变更申请单、RTM、评审纪要 |
| **数据基础** | 理解核心数据指标，能用SQL/Excel进行基础数据提取与分析 | 数据分析报告 |

## 售前工程师能力栈

| 能力维度 | 具体要求 | 输出物 |
|---------|---------|--------|
| **技术硬实力** | 深入理解产品技术架构、核心功能、性能指标、部署方式；熟悉竞品技术路线与差异化优势 | 技术白皮书、竞品对比分析 |
| **方案设计** | 能根据客户个性化需求（预算、现有系统、特殊场景）定制解决方案 | 技术方案书、架构设计图 |
| **方案呈现** | 具备场景化演示能力，能制作高质量PPT，能进行公开演讲与答疑 | 演示PPT、Demo脚本、演讲稿 |
| **招投标支持** | 能独立完成投标方案撰写、技术应答、标书讲解与澄清 | 投标文件、技术应答书 |
| **商务洞察** | 理解客户决策链、预算范围、采购流程，能识别并捕捉商业机会 | 商机分析报告、客户画像 |
| **项目管理** | 能把控售前阶段节点，协调内外部资源，确保方案从"设计"到"落地"无缝衔接 | 项目计划、资源协调清单 |

## 知识储备要求

**需求分析领域**：需求工程理论（Karl Wiegers《软件需求》）、UML 建模、敏捷需求管理（用户故事/故事地图/INVEST）、BABOK 业务分析框架。

**技术基础**：软件架构模式（单体/微服务/Serverless/云原生）、数据库基础（关系型/NoSQL、数据建模）、API 设计（RESTful/GraphQL/RPC）、安全与合规（等保/GDPR/数据加密）。

**行业洞察**：AI 大模型、低代码/无代码、数字孪生等前沿趋势；所服务行业的业务逻辑、监管政策、竞争格局；主流竞品技术路线与差异化。

**商务基础**：招投标法规与流程、商务谈判、合同条款（SOW/SLA/验收标准）、财务基础（ROI/TCO/CAPEX/OPEX）。
