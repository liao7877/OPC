# presales 输出自检清单（checklists）

> SKILL.md 的 Level 3 附属：交重要稿件前逐项过，不是走形式——每条对应一种真实翻车场景。

## 需求文档自检

- [ ] 每个需求都有明确的编号和优先级
- [ ] 所有术语在文档中有统一定义
- [ ] 业务流程覆盖正常流、异常流、边界条件
- [ ] 每个功能需求都有对应的验收标准
- [ ] 非功能需求（性能、安全、兼容性）已明确
- [ ] 数据埋点需求已列出
- [ ] 需求变更记录完整
- [ ] 文档已同步所有干系人并获确认

## 售前方案自检

- [ ] 客户痛点分析准确，有数据支撑
- [ ] 方案架构清晰，技术可行性已验证
- [ ] 价值量化具体，ROI可计算
- [ ] 实施路径分阶段，里程碑明确
- [ ] 风险识别全面，应对措施可行
- [ ] 竞品对比客观，差异化优势突出
- [ ] 文档排版专业，无错别字和格式错误
- [ ] 演讲稿已准备，Demo已预演
