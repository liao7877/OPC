# presales 文档模板与话术提纲（templates）

> SKILL.md 的 Level 3 附属：动笔前按任务类型取对应框架填空，不临场发挥。

## PRD 文档标准模板（大厂规范）

```markdown
# PRD文档：[产品/功能名称]

## 1. 文档概述
### 1.1 修订记录
| 版本 | 时间 | 修订人 | 修订内容 | 备注 |

### 1.2 项目背景
- 现状描述 + 影响范围 + 期望效果

### 1.3 需求目标
- 明确可量化的成功指标（如：转化率提升X%、操作步骤减少Y步）

### 1.4 阅读对象
- 产品、设计、开发、测试、项目经理、业务方

### 1.5 专业术语
- 列出文档中涉及的专业名词及解释

## 2. 项目概述
### 2.1 产品路线图
### 2.2 功能清单（Feature List）
### 2.3 产品结构设计
### 2.4 业务流程图（泳道图/活动图）
### 2.5 需求列表（Backlog）

## 3. 产品规范
### 3.1 页面设计规范
### 3.2 产品状态规范
### 3.3 操作提示规范
### 3.4 数据加载规范
### 3.5 消息通知规范

## 4. 功能需求（核心章节）
### 4.1 功能总览
### 4.2 页面原型（含交互说明）
### 4.3 用例描述（Use Case）
  - 用例名称、参与者、前置条件、后置条件、主流程、异常流程
### 4.4 业务规则
  - 校验规则、计算逻辑、权限规则、状态流转规则

## 5. 非功能需求
### 5.1 性能需求（响应时间、并发量、吞吐量）
### 5.2 安全需求（数据加密、权限控制、等保合规）
### 5.3 兼容性需求（浏览器、设备、系统版本）
### 5.4 可用性需求（无障碍、国际化）

## 6. 数据需求
### 6.1 数据埋点清单
### 6.2 数据指标定义
### 6.3 数据报表需求

## 7. 附录
### 7.1 接口需求（如有）
### 7.2 附件素材（设计稿、参考文档）
### 7.3 风险与依赖
```

## 客户需求访谈提纲

1. 【背景】贵司目前的[业务领域]整体运作流程是怎样的？
2. 【痛点】在日常工作中，最让您头疼的3个问题是什么？
3. 【影响】这些问题对业务/团队/客户造成了什么具体影响？（量化）
4. 【期望】如果有一套理想的解决方案，您希望它帮您实现什么？
5. 【约束】在推进这个项目时，有哪些必须考虑的约束条件？（预算、时间、技术、合规）
6. 【决策】这个项目的决策流程是怎样的？关键决策人有哪些？
7. 【竞品】您目前是否了解或使用过类似的解决方案？体验如何？

## 方案价值呈现话术框架

- 【痛点共鸣】"根据我们的调研，贵司目前在[具体场景]面临[具体痛点]..."
- 【方案概述】"我们的解决方案通过[核心技术/方法]，帮助您[实现目标]..."
- 【价值量化】"预计上线后，可实现[具体指标提升]，每年节约[金额]/提升[效率]..."
- 【落地保障】"整个实施周期预计[X个月]，分[X个阶段]推进，我们有[X个同行业成功案例]..."
- 【风险兜底】"针对您担心的[具体风险]，我们的应对措施是[具体方案]..."

## 需求评审会议议程

1. 需求背景与目标回顾（5分钟）
2. 业务流程与功能演示（15分钟）
3. 技术可行性讨论（15分钟）
4. 风险与依赖识别（10分钟）
5. 排期与资源确认（10分钟）
6. 待办事项与责任人明确（5分钟）
