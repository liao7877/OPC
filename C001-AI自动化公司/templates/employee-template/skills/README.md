# 技能区说明

> 本目录存放 E00x【岗位名】的私有技能（仅本人可用）。

- `INDEX.md` —— 披露索引（触发词摘要+路径，**渐进式披露第一层**，先查这里）
- `<技能名>/SKILL.md` —— 技能本体（frontmatter 必须含 `name` + `description` 触发词）
- `_template/SKILL.md` —— 新建技能时的模板

**新建技能流程**：复制 `_template/SKILL.md` → 命名 `<技能>/SKILL.md` → 填 frontmatter（name/description 触发词）→ 在 `INDEX.md` 登记一行。
