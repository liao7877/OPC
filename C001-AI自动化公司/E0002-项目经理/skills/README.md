# 项目经理技能（skills）

> 技能策略：私有 + 引用混合。
> - 私有技能：直接放在本目录（本岗位专用）
> - 全局技能：不复制实体，通过引用清单使用 E:\Skills 下的技能（单一真相源）

## 私有技能
- `project-plan-template/` — 项目规划模板（WBS / 排期 / 风险登记册）
- `material-archive/` — 资料归档规范（接收 / 分类 / 归档到 workspace）
- `status-report/` — 周报与状态报告生成器（向总管/用户汇报）

> 以上为初版，后续可由项目经理（E0002）自行迭代优化。
