# 数据分析模板（data-analysis-template）

> 用途：把分析类任务产出成规范、可读的报告。
> 级别：E0001 私有技能（示例）。

## 报告结构
1. 结论先行（一句话核心发现）
2. 背景与目标（为什么分析）
3. 数据 / 输入（来源、范围）
4. 分析过程（方法、关键步骤）
5. 发现与洞察（要点列表）
6. 建议与下一步

## 执行步骤
1. 读任务输入（来自总管派发的 task.md 或对话）
2. 明确分析目标，缺数据先问
3. 执行分析（调用工具 / 技能）
4. 按结构产出，表格化呈现
5. 输出到任务目录 deliverables/，交总管待审

## 注意事项
- 结论先行、不注水
- 数据存疑就标出，不编造
