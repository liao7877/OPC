# 实体命名解耦：显示名与物理路径分离（决策 #17）

## 目标口径

- **E/T/P 实体目录改为 ID-only**（`E0001/`、`T001/`、`P0001/`），显示名唯一真相源：
  - 员工 → `roster.md`「岗位」列（已有权威列，生成器改从这里取）
  - 团队/项目 → `team.md`/`project.md`「名称：」字段（已有，不动）
- 此后**员工改名 = 改 roster 一行岗位 + 改人设文案，零文件系统波及**（junction、看板、引用全都不动）。目录名带不带显示名都兼容（渐进迁移），但显示名一律取自登记字段，永不取自目录名。
